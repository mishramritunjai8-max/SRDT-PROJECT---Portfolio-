MRITUNJAI'S BASIC HTML PORTFOLIO
================================

This is a beginner-style website made with simple HTML and basic CSS.
It uses a visible light-blue background, dark text, simple colored headings,
plain text links, and a basic table. It does not use cards or gradients.

FILES
-----
index.html          Home page
about.html          About page and AI introduction video
achievements.html   Achievement links and mark sheet table
projects.html       Project and profile links
style.css           Basic colors and text styling
images/profile.png  Profile image
assets/ai-intro.mp4 AI introduction video
documents/10th-marksheet.pdf  Uploaded Class 10 mark sheet
documents/12th-marksheet.pdf  Uploaded Class 12 mark sheet

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Open the extracted mritunjai_basic_portfolio folder in VS Code.
3. Open index.html in your browser.
4. Use the text links at the top to visit each page.

MARK SHEETS
-----------
The uploaded PDFs are already included in the documents folder and linked from
the Achievements page. If you publish the website online, remember that these
documents may become publicly accessible. Consider removing personal details
before publishing them.

HOW TO CHANGE COLORS
--------------------
Open style.css and change the background-color, color, or heading colors.
